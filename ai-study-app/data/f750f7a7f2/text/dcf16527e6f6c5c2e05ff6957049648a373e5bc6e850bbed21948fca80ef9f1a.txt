3.3 · NÂNG CAO
Phát Hiện Ngoại Lệ Bằng Phương Pháp IQR
def tim_ngoai_le_iqr(nhom):
    q1, q3 = nhom.quantile([0.25, 0.75])
    iqr = q3 - q1
    can_duoi, can_tren = q1 - 1.5*iqr, q3 + 1.5*iqr
    return (nhom < can_duoi) | (nhom > can_tren)

df["ngoai_le_iqr"] = df.groupby("Ma_CP")["loi_suat"].transform(tim_ngoai_le_iqr)
IQR (khoảng tứ phân vị) là phương pháp thay thế cho Z-score, ít bị chính các giá trị ngoại lệ 'kéo lệch' kết quả hơn.

    ls_nam = loi_suat_ngay.mean() * so_ngay_nam
    bd_nam = loi_suat_ngay.std() * np.sqrt(so_ngay_nam)
    return (ls_nam - rf) / bd_nam

def tinh_max_drawdown(gia_series):
    gt_tich_luy = (1 + gia_series.pct_change().fillna(0)).cumprod()
    dinh_cao_nhat = gt_tich_luy.cummax()
    return ((gt_tich_luy - dinh_cao_nhat) / dinh_cao_nhat).min()
Hai chỉ số đánh giá hiệu suất đầu tư quan trọng bậc nhất, tính hoàn toàn không cần vòng lặp nhờ vector hóa NumPy/Pandas.

Retry Với Exponential Backoff
import time

def goi_api_voi_retry(ham_goi_api, so_lan_thu=3, cho_ban_dau=1):
    for lan_thu in range(so_lan_thu):
        try:
            return ham_goi_api()
        except Exception as e:
            thoi_gian_cho = cho_ban_dau * (2 ** lan_thu)
            print(f"Lần {lan_thu+1} thất bại, chờ {thoi_gian_cho}s...")
            time.sleep(thoi_gian_cho)
    return None    # hết lượt thử -- chuyển sang dữ liệu dự phòng
Thời gian chờ tăng GẤP ĐÔI sau mỗi lần thất bại -- tránh làm quá tải server đang gặp sự cố.
