Vì Sao Python Trong Tài Chính?
Python là ngôn ngữ lập trình cấp cao, cú pháp rõ ràng, dễ đọc — rút ngắn thời gian phát triển

1.1 · CÔNG CỤ LẬP TRÌNH
Môi Trường Jupyter Notebook
Jupyter Notebook là môi trường lập trình tương tác, chạy từng ô lệnh (cell) độc lập
Hai loại cell chính: Code cell (chạy code Python) và Markdown cell (văn bản, giải thích, công thức)
Kết quả (số liệu, bảng, biểu đồ) hiển thị ngay bên dưới cell — rất phù hợp cho phân tích dữ liệu khám phá
Có thể lưu lại toàn bộ quá trình phân tích: code, kết quả, và diễn giải trong cùng một file (.ipynb)
Là công cụ tiêu chuẩn trong ngành khoa học dữ liệu và tài chính định lượng (quant finance)
Môi Trường Jupyter Notebook

1.1 · THỰC HÀNH NHANH
Ô Lệnh Đầu Tiên Trong Jupyter Notebook
# Đây là một code cell -- nhấn Shift + Enter để chạy
print("Xin chào FinTech!")

# Python có thể tính toán tài chính đơn giản ngay lập tức
gia_von = 100_000_000      # 100 triệu đồng
loi_nhuan = 8_500_000       # 8.5 triệu đồng lợi nhuận
ty_suat_loi_nhuan = loi_nhuan / gia_von
print(f"Tỷ suất lợi nhuận: {ty_suat_loi_nhuan:.2%}")
Dấu gạch dưới trong số (100_000_000) chỉ giúp dễ đọc -- Python bỏ qua nó khi tính toán.
Ô Lệnh Đầu Tiên Trong Jupyter Notebook

1.2 · PYTHON TRONG THỰC TẾ
Ứng Dụng Của Python Trong FinTech
Giao dịch thuật toán (Algorithmic Trading): tự động phân tích và đặt lệnh mua/bán theo chiến lược
Phân tích rủi ro (Risk Analysis): định lượng rủi ro thị trường, rủi ro tín dụng, rủi ro thanh khoản
Phát hiện gian lận (Fraud Detection): dùng Học máy phát hiện giao dịch bất thường theo thời gian thực
Chatbot và trợ lý ảo tài chính: tự động hóa tư vấn, chăm sóc khách hàng ngân hàng số
Blockchain và tiền mã hóa: xây dựng và phân tích hợp đồng thông minh, sổ cái phân tán
Robo-advisor: tự động đề xuất và quản lý danh mục đầu tư cá nhân hóa
